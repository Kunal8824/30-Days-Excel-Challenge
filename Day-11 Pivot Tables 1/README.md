# Day 11 — Introduction to Pivot Tables 📊

**Date:** October 3, 2026

Day 11 focused on building and configuring Pivot Tables in Excel to rapidly summarise, aggregate, and structure large datasets without formulas.

## What I Learned & Practiced

* Creating Pivot Tables from structured tabular data
* Structuring layout by dragging fields into rows, columns, values, and filters
* Customising calculation types using Value Field Settings
* Grouping dates and numbers into meaningful buckets and time horizons

## Practice

Built an interactive summary report from raw transactional data by arranging category and regional fields, adjusting value settings to show both counts and averages, and grouping dates into months and quarters for trend analysis.

## Key Takeaway

Learned how Pivot Tables turn large, complex datasets into flexible, multi-dimensional summaries in seconds, drastically speeding up data analysis.
