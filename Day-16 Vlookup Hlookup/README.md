# Day 16 — Lookup Functions: VLOOKUP & HLOOKUP 📊

**Date:** October 8, 2026

Day 16 focused on understanding vertical and horizontal lookup mechanics in Excel to retrieve matching data across tables accurately and handle lookup errors.

## What I Learned & Practiced

* Mastering VLOOKUP syntax, arguments, and table array boundaries
* Understanding exact match (FALSE/0) versus approximate match (TRUE/1) applications
* Using HLOOKUP for horizontal datasets and row-based lookups
* Troubleshooting and resolving classic errors like #N/A, #REF!, and data-type mismatches

## Practice

Built dynamic lookup tables pulling product details, pricing tiers, and tax rates from separate reference sheets using VLOOKUP and HLOOKUP, while cleaning lookup keys with TRIM to prevent matching failures.

## Key Takeaway

Learned how lookup functions automate relational data retrieval between separate tables, and how strict column/row indexing and matching modes prevent common formula errors.
