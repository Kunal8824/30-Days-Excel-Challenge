# Day 13 — Data Validation & Input Controls 📊

**Date:** October 5, 2026

Day 13 focused on mastering Data Validation in Excel to enforce entry rules, build interactive drop-down menus, and prevent user input errors.

## What I Learned & Practiced

* Building dynamic drop-down lists from named ranges and tables
* Setting up input rules and restrictions for dates, numbers, and text lengths
* Configuring custom input prompts and stop/warning error alerts
* Creating multi-level dependent/cascading drop-down lists using the INDIRECT function

## Practice

Built a validated data entry form featuring primary and dependent drop-down selections, restricted invalid date and value inputs, and created helpful custom error alerts to guide the user.

## Key Takeaway

Learned how Data Validation prevents bad data at the point of entry, safeguarding dataset structure and ensuring downstream analysis runs smoothly without data cleaning overhead.
