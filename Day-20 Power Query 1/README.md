# Day 20 — Introduction to Power Query: Get & Transform 📊

**Date:** October 12, 2026

Day 20 focused on exploring Excel's Get & Transform (Power Query) engine to import external datasets, navigate the Query Editor, and construct repeatable data transformation workflows.

## What I Learned & Practiced

* Connecting to external data sources using Get & Transform
* Navigating the Power Query Editor ribbon, formula bar, and preview grid
* Managing and editing transformation recipes via the Applied Steps pane
* Configuring background and scheduled auto-refresh rules for linked queries

## Practice

Imported raw CSV and workbook data into Power Query, applied structural transformations including column renaming, type coercion, and row filtering, audited changes sequentially in Applied Steps, and loaded clean outputs directly into an auto-refreshing Excel table.

## Key Takeaway

Learned how Power Query automates the entire ETL (Extract, Transform, Load) pipeline, turning repetitive data cleaning routines into a single-click refreshable process.
