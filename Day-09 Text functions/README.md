Day 9 focused on mastering text manipulation and data cleaning functions in Excel to parse, transform, and standardise raw text datasets effectively.

## What I Learned & Practiced

* Using LEFT, RIGHT, and MID for targeted text extraction
* Combining text seamlessly with CONCATENATE and TEXTJOIN
* Removing excess whitespace and non-printable characters using TRIM and CLEAN

## Practice

Cleaned and transformed unformatted string data by stripping irregular spaces with TRIM and CLEAN, isolating specific identifiers using LEFT, RIGHT, and MID with FIND, and generating dynamic concatenated values using TEXTJOIN.

## Key Takeaway

Learned how combining text functions automates the process of parsing messy strings, ensuring high data quality and consistency across datasets.
