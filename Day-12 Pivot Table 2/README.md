# Day 12 — Advanced Pivot Tables & Interactive Reporting 📊

**Date:** October 4, 2026

Day 12 focused on enhancing Pivot Tables with custom calculated fields, visual slicers, linked Pivot Charts, and managing dynamic data refreshes.

## What I Learned & Practiced

* Creating Calculated Fields to perform custom metric calculations directly within Pivot Tables
* Adding and formatting Slicers for interactive, multi-dimensional filtering
* Building linked Pivot Charts for dynamic, responsive visual summaries
* Configuring data refresh settings to update reports as source data changes

## Practice

Built an interactive mini-dashboard by adding custom profit margin calculations via Calculated Fields, connecting visual Slicers across tables, embedding responsive Pivot Charts, and verifying automatic updates upon refreshing source records.

## Key Takeaway

Learned how Slicers, Calculated Fields, and Pivot Charts turn flat tabular summaries into intuitive, interactive reporting dashboards that stay up-to-date with changing data.
