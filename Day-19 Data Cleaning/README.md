# Day 19 — Built-in Data Cleaning & Transformation Tools 📊

**Date:** October 11, 2026

Day 19 focused on using Excel’s native data transformation features to clean datasets rapidly, remove redundant entries, and parse structured text without complex formulas.

## What I Learned & Practiced

* Using Find & Replace with wildcards and formatting criteria for bulk edits
* Deduplicating datasets accurately using the Remove Duplicates utility
* Splitting combined text fields with Text to Columns (delimited and fixed-width)
* Automating text extraction, combining, and formatting using Flash Fill (Ctrl + E)

## Practice

Processed an uncleaned contact export by splitting combined names and email addresses with Text to Columns, stripping formatting inconsistencies across thousands of cells via Find & Replace, eliminating repeated records, and generating standardized username handles instantly with Flash Fill.

## Key Takeaway

Learned that combining native tools like Text to Columns and Flash Fill speeds up initial data preparation workflows significantly, providing a quick, formula-free way to sanitize raw inputs before analysis.
