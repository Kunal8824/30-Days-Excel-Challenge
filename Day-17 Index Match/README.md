# Day 17 — Advanced Lookups: INDEX & MATCH 📊

**Date:** October 9, 2026

Day 17 focused on mastering the INDEX and MATCH combination in Excel to overcome VLOOKUP limitations, perform left lookups, and execute dynamic two-way matrix searches.

## What I Learned & Practiced

* Using INDEX to retrieve cell values based on specific row and column numbers
* Using MATCH to dynamically locate the position of values in rows or columns
* Performing left lookups where the return column is to the left of the lookup key
* Building dynamic two-way (grid/matrix) lookups combining horizontal and vertical headers

## Practice

Replaced fragile VLOOKUP formulas with dynamic INDEX & MATCH formulas to pull employee IDs and product codes located to the left of reference columns, and created a two-way lookup matrix pulling pricing based on variable product rows and regional columns.

## Key Takeaway

Learned how INDEX & MATCH provides a far more flexible, resilient alternative to VLOOKUP by decoupling lookup arrays from return arrays and enabling lookups in any direction.
